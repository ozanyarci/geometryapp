Yandaki şekilde ABC açısı ile KLM açısı veriliyor.

Yukarıdaki verilere göre, ABC açısı ile KLM açısının kesişimi (ABC ∩ KLM) aşağıdakilerden hangisidir?

  • A) {P, Q}
  • B) {R, S}
  • C) {P, Q, R, S}
  • D) PQRS dörtgeni
  • E) {B, L}
Cevap anahtarı ve kısa çözümler
  1. C — Dairesel grafik toplamı 360°'dir: x + 160 + 115 = 360 → x + 275 = 360 → x = 85°
  2. C — Açıya x diyelim. Bütünleyeni (180 − x), tümleri (90 − x). 180 − x = 4(90 − x) − 15 → 3x = 165 → x = 55°
  3. C — (90 − x) + (180 − x) = 190 → 270 − 2x = 190 → 2x = 80 → x = 40°; Bütünleyeni = 180 − 40 = 140°
  4. D — Karşı durumlu açılardan: a + 2b = 180 ve 3a + b = 180. İkinci denklemden b = 180 − 3a yazıp 1. denklemde yerine koyarsak a + 360 − 6a = 180 → 5a = 180 → a = 36°, b = 72°. Buradan b/a = 72/36 = 2
  5. D — Kolları aynı yönlü paralel açılar eşittir: 5x − 12 = 3x + 24 → 2x = 36 → x = 18°; m(ABC) = 5(18) − 12 = 78°
  6. B — A noktası etrafında m(KAL) + m(BAC) = 180° → 160° + m(BAC) = 180° → m(BAC) = 20°. ABC dik üçgeninde x = 90 − 20 = 70°
  7. C — Açılar ışınların noktalar kümesidir. İki açının kesişimi ışınlarının kesiştiği 4 ayrık noktadır: {P, Q, R, S}
